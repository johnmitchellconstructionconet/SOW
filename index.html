Trade & Selection Fields

Every trade defaults to not included. Click "Include: Yes" to open it up. Each field shows its control type — Pick One (radio), Pick Any (checkboxes), Per-Location (add a row per instance), or Required Input (free text). The small dropdown next to each answer tracks whether it's Confirmed, Reported, Assumed, Unknown, or needs Investigation — same convention as your written SOWs.

Manage Scope Items

Add trades, fields, and options here as you see them come up in the field — no code changes needed. This saves to your browser automatically and applies immediately to Scope Builder. It's saved on this computer/browser only — the file itself never changes, so if you move to a new computer, export/re-import or re-add anything custom.

Add an Option to an Existing Field

First ask: is the new item an alternative to the choices already listed (only one applies at a time), or is it an independent add-on that could apply alongside any of them (like "lighted," "heated," or "with grab bar")? If it's an add-on, it usually belongs as its own separate field, not another option in this list — see "Add a New Field" below with Pick Any as the control type instead.

Add a New Field to This Trade

Use this for independent add-ons/modifiers (pick a Pick Any control type) as well as for entirely new decisions this trade needs. Don't fold an add-on into an existing single-choice field — see the reminder above.
